将近一个月没有更新，本博客自创立以来最久的一次……

没更新的时间里我在做：

- 一个合唱的混音项目
- 一个 agent 项目
- 关心父母

因为时间、精力等一系列原因，搁置了：

- 健身
- 更新博客
- 给自己一些「空」的时间让灵感生长
- 做自己的音乐

## 不要熬夜

混音项目是从七月初开始有计划地推进的。由于只能在下班后进行，加上6月下旬搬家后还需要一段时间适应，我又不自觉地开始熬夜。工作强度最高的两周，基本都是1-2点睡觉，健身的习惯也搁置了。

熬夜给我的生活带来的影响是全方位的。从身体上来说，我更难以控制饮食，蔬菜吃得更少了，💩💩 也变得有点困难（这在我身上几乎很少出现）；精神上，我白天更困，一到晚上却又精神起来。于是即使混音项目结束后，我还是继续熬了一周的夜。直到周五彻底累趴，从11点多睡到第二天9点，总算恢复了一点。

如果只是熬夜倒也不会这么困，但上周三、这周五都是5点多起床，我觉得不规律的作息才是罪魁祸首。上周三是公司体检，这周五是帮爸爸去医院问诊；因为都要赶一小时地铁去医院，再加上我不想请太久的假，只能赶6点多的早班车。上周三其实还好，但这周五我是真的困得不行：路上一直在打盹，走到医院门口买了杯咖啡灌下去（超级难喝的便利店咖啡）也不管用；排队等号时靠在座位上直接睡着了，才终于恢复了一点精力。

这个月我还睡过头两次，都是早上醒来后着急忙慌地和领导请假（内心非常不好意思）。好在我所在的部门对按时上班的要求没有那么高，所以没造成什么严重后果。

今天能坐在这里写博客，也是因为周末两天都睡饱饱了。一定要好好睡觉！以后不因为无关紧要的事情熬夜/牺牲自己的健康了！

## 保持健康

上周的体检，医生说我有脂肪肝和肾结石！TuT

脂肪肝前几年就查出来了，但我没有特别重视。虽然有在控制饮食，比如不吃太多肥肉、油炸的东西，但总体而言还是没有少吃…… 昨天看了 Wiwi 写的关于[矫枉必须过正](https://wiwi.blog/blog/be-extreme/)的文章，痛定思痛，决定在八月戒酒。至于吃饭的规则，我还没想好，你有什么建议吗？

锻炼也搁置蛮久了，很久没做力量训练，最近去健身房都在爬坡。八月会去得更频繁一点。

## 生活重心

总的来说，7月是忙着「做别人的事」的一个月：给公司做开发、给朋友做混音、给家人更多的关心。至于「自己的事情」，则被牺牲了不少。这个月明显感觉自己被事情推着走，没什么精力分配给自己想做的事，八月我会慢慢调整回来。不过，如果平衡只是因为没有「别人的事情」找上门，那新的事情找来，岂不是又回到原点？我给自己的解决方案是：推掉不想做的事情。比如流程固定、无法实践新技术的混音，又或是没那么着急的工作需求。这两年接混音时，我确实正在实践这种策略；可能工作和生活上也需要更多练习吧～

## 成就

虽然很累，我还是取得了一些小小成就：

- 混音的结果我非常满意：高达87轨（低质量）人声，我设法将它们融合成了一个大合唱。这次混音在文件管理、时间安排、混音技法上也都有进步，能做到这个程度，我还是很开心的。
- 工作上，交付了一个 agent 原型，RAG 的部分、Agent 架构都是我设计的（也有很多 Codex 的帮助）；编码部分则主要靠 Codex，我做了一些 review。这期间积累了很多 Agent 落地的经验：基于向量库的 RAG 为什么效果不好、多 Agent 系统如何设计、如何在可靠性和灵活度之间找到平衡，以及 Skill/MCP/Tools等概念之下哪些真正可靠、哪些又是 FOMO 情绪的产物。每个主题都可以拿出来写篇文章，我会慢慢更新到博客上！

## 总结

我会更频繁更新的…… 嘿嘿
